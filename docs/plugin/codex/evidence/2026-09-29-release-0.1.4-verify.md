## 測っていないこと

- **仕様書 04**（判定本体が欠けたら止める）と **05**（記録の置き場に書けなくても失敗しない）の実機での発火。どちらも導入を壊すか sandbox の設定を変えないと再現できない。スクリプト単体のテストのみ
- 01 のうち `Update File` / `Delete File` / `Move to`、複数ファイルのパッチ
- 02 のうち `bash -c "…"`・括弧・`npm --prefix`
- ブランチが別のツール用のときの警告（`claude/*` ブランチでは起動していない）
- **Claude Code 側の発火。** 版が 0.1.4 に上がることだけを確認した。導入先（`/Users/masanori/aidd-pipeline-plugin-test`）ではプラグインが disabled で、hook は動いていない
- `aidd-vkumai` の Supabase 自動停止（導入先での発火）
- ChatGPT desktop app、Codex CLI 0.158 系
