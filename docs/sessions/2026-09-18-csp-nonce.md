# 2026-09-18 CSP を nonce ベースへ広げる（issue #757 の 16 の残り。証明フェーズ 2 本目）

## 30秒サマリー
- 変更概要: CSP が `frame-ancestors 'none'` の 1 ディレクティブだけだったのを、proxy で nonce を作る形に広げて `script-src` を実際に絞る
- リスク: 高（全ページのスクリプト実行に効く。締めすぎると画面が全壊する）
- 変更領域: ロジック（proxy）・設定・テスト・E2E。DB・RLS・migration は無変更
- 証拠状態: 実測 6 件（単体 2295・E2E 88・lint・型検査・RED 方向 2 通り・実ブラウザでの violation 0 件）/ 未検証 1 件（CI）
- 影響範囲: 全ページ（proxy の matcher が `_next/static` と画像以外の全部を通る）
- ロールバック可能性: 高（migration 無し。revert のみ）

レビューしてほしい点:
1. `style-src` に `'unsafe-inline'` を残す判断（A-1）。53 ファイルがインライン style 属性を使う
2. CSP の出所を `proxy.ts` 1 か所にし、`next.config.ts` から外した判断

## 00 目的・影響範囲・対象外
- 目的: XSS が入ったときに実行を止める手段が無い状態（`script-src` 無し）を解消する
- 対象外: インライン style の CSS 化 / CSP violation の収集（report-to。本番の監視 #757 の 8 と一体で外部待ち）/ SRI
- 依存の変更: なし

## 01 画面がどう変わったか
- **見た目の変更なし**。実ブラウザで確認済み（フォント・色・インライン style が効いたまま）

## 02 内部でどう守っているか
- `src/lib/security/csp.ts`: nonce 生成と CSP 組み立て。**出所はここ 1 か所だけ**
- `src/proxy.ts`: `proxy()` が nonce を 1 個作り、`handleRequest()` の戻りに CSP を載せる
  - **唯一の入口にした理由**: proxy は 6 か所から応答を返す。各所で付ける形だと、返り口を足した人が忘れた経路だけ CSP 無しになる
  - 転送リクエスト側にも同じ CSP と `x-nonce` を載せる。**Next.js は転送リクエストのヘッダから nonce を読む**ので、応答側だけでは nonce がタグに載らない（= CSP は出るのにスクリプトが全部ブロックされる、という静かな失敗）
- `next.config.ts`: CSP を削除。他 6 ヘッダは据え置き

## 03 誰が操作できるか
- RLS・権限の変更: **なし**
- 該当する約束: 新規なし（CSP は約束カタログの ID を持たない。`docs/agents/threat-model.md` の XSS 系に対応）

## 後任AIへの注意
- **応答ヘッダだけに CSP を付けても nonce はタグに載らない。** 転送リクエスト側にも同じ値が要る
- **CSP を `next.config.ts` に戻さない。** 二重定義になり、どちらが効いているか読めなくなる（検査が落とす）
- `style-src` の `'unsafe-inline'` は**意図して**残している。外すと 53 ファイルの UI が壊れる

## ハーネスの成績（この issue で起きたこと）

- **`git hook（commit-msg / pre-push）` が見逃した（再発）**: この worktree の `config.worktree` に
  `core.hooksPath` の絶対パス上書き（実在しないディレクトリ）が**2026-09-18 時点でも残っていた**。
  git は存在しない hooksPath を黙って無視するため、**このセッション中ずっと hook が動いていなかった**。
  結果、同セッションで作った CI 修正 4 件のコミット（`.github/` `scripts/` のみ）が**凍結 H-014 を素通り**した。
  E-092 と同じ穴で、`harness-freeze.md` が「この検査は機械化していない」と書いている箇所そのもの。
  `git config --worktree --unset core.hooksPath` で解除した。
- **Next.js のドキュメント参照ルールが止めた**: `node_modules/next/dist/docs` を読む規約
  （`docs/agents/common.md`）に従って読んだことで、「nonce は**転送リクエストの**ヘッダに載せないと
  Next.js がタグに付けない」ことが分かった。応答ヘッダだけの実装は**CSP は正しく出るのに全スクリプトが
  ブロックされる**という静かな失敗になり、単体テストでは捕まらない。
