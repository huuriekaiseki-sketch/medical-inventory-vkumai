# スケルトン動作検証プラン

## Context
記事を参考にNext.js 16 + Supabase + Vitestプロジェクトを初期化した段階。CRUD実装の前に、スケルトン自体が正常に動作するかを検証する。

## 検証項目

### 1. `npm run lint` — ESLint
- そのまま実行して通るか確認

### 2. `npm test` — Vitest
- テストファイルが0件のため、空テスト実行が正常終了するか確認
- もしエラーになる場合、ダミーテストを1つ追加して通す

### 3. `npm run build` — Next.js本番ビルド
- TypeScriptコンパイル + ビルドが通るか確認
- `.next/` が正常に生成されるか

### 4. `npm run dev` — 開発サーバー起動
- `localhost:3000` でボイラープレートページが表示されるか確認

## 想定される問題と対処

| 問題 | 対処 |
|------|------|
| Vitest「テストが見つからない」エラー | `src/__tests__/smoke.test.ts` にダミーテスト追加 |
| ESLintの未使用import警告 | ボイラープレートなので無視or修正 |
| ビルドエラー（型エラー等） | tsconfig / next.config 調整 |

## 検証の順序
lint → test → build → dev の順で実行（軽いものから）

## 成果物
- 全コマンドの実行結果レポート
- 必要に応じた最小限の修正（ダミーテスト等）
