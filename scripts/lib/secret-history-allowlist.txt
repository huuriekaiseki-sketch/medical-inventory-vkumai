# git 履歴に残っているが秘密ではないと確認した値の一覧。
# 形式: <一致した文字列の SHA-256>  <理由>
#
# WHY(値そのものではなくハッシュで書く): 値を書くと**この許可リスト自身が走査に引っかかる**
#      （追跡ファイルの走査も履歴の走査も、秘密の形をした文字列を探すため）。
#      ハッシュなら秘密の形にならず、実物と突き合わせることもできる。
#
# WHY(履歴の走査にだけ効かせる): **いまのファイル**の走査（check-secret-leak.test.sh）には
#      使わない。履歴は書き換えられない（clone した全員が持っている）ので許すしかないが、
#      新しく入れようとしたものは無条件で止める。
#
# 足すときの条件（1 つでも欠けたら足さない）:
#   1. その値が本物の秘密でないことを**確かめた**（発行元で無効・そもそも架空・公開値）
#   2. 本物だったなら**先にローテーションした**うえで、履歴に残るものとして登録する
#   3. 理由に「何の値で、なぜ安全か」を書く。「テスト用だから」だけでは足りない
#
# 使い方: printf '%s' '<一致した文字列>' | shasum -a 256
